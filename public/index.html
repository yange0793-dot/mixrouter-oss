会话绑定

每个对话锁定一个渠道；改绑立即对该对话生效，不影响其他对话。ZCode 流量归入所选协议组，这里不识别独立的 ZCode 会话。

每个对话锁定一个渠道；改绑立即对该对话生效，不影响其他对话。每行「配置 Key / 槽位」可为该会话单独指定渠道 Key 或覆盖槽位落点：取 Key 的顺序是「该槽位指定 → 本会话该渠道 Key → 渠道当前 Key」，显式指定的 Key 不存在或停用时请求直接失败，不会改用其他 Key。保存只影响该会话后续新请求，不改变渠道当前生效 Key；清空或解绑会连同这些配置一起删除。
