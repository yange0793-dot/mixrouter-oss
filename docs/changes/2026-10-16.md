## 代理请求读体

- 将 `proxyHandler()` 内的上传缓冲与有界排空移入 `lib/http/body.js` 的 `readProxyBody()`。
- 主入口只提供字节上限、额外排空预算、排空时限、协议错误响应及两个计数回调；路由、转换、会话与上游生命周期仍由原入口负责。
- 保留原有语义：正常上传按字节计量，拼接后统一解码 UTF-8；释放上传块引用后交给请求处理回调。
- 超限后释放已收缓冲，丢弃剩余上传；排空结束、出错、连接关闭、预算击穿或时限到达时，413 最多发送一次。
- 触发超限的原始数据块不计入额外排空预算，与旧入口一致。预算击穿后暂停读入，时限或预算触发的销毁仍等待响应 `finish` / `close`。
- JSON 深度与对象校验、错误正文、`bodyDrainAborts` / `bodyDrainTimeouts` 的统计口径不变。未增加正常请求提前断开时的新处理策略。
